# 场景质量审查

审查日期：2026-08-20

## 共性问题与修复

此前所有场景都只做生成前提示词编译，没有检查生成结果是否真正符合所选工作流。模型只要成功返回图片，网站就会直接展示，因此会出现主体丢失、真实照片区域被重画、擅自加字或风格偏离。

本次增加两级防线：

1. “自然人像补光”不再调用生图模型，只用读图模型定位人物，然后在浏览器中对原始像素做局部曝光、高光和色温调整。
2. 其余创意场景在首张候选图生成后，由读图模型同时检查原图和结果。若结果偏离规则，界面会显示问题，并把纠偏要求自动带入用户点击的“再生成一次”。每次操作只生成一张，避免请求超时和重复扣费。

## 分场景结论

| 场景 | 当前性质 | 主要风险 | 本次处理 |
| --- | --- | --- | --- |
| 极简 Zine | 作者 README 预览；运行时为生成式适配 | 生成结果可能留白不足或擅自虚构文字 | 检查唯一视觉锚点、留白和文字许可 |
| 结构记忆编辑 | 独立实现 | 最容易把“真实摄影区”也重画成插画 | 把真实摄影区消失列为严重失败 |
| 实景纸拼 | 独立实现 + 本地合成 | 生图模型会把应保留的照片区域也重画成插画 | 模型生成同源纸媒转译层；网页再覆盖真实摄影锚点，提示词、品牌和素材均不来自第三方 Skill |
| 场景抽象 | 独立实现，允许重创作 | 可能只剩通用插画，丢失原图独有线索 | 按主体关系、方向和场景辨识度验收，不使用第三方 Skill 内容 |
| 照片遗迹 | 作者 README 预览；运行时为生成式适配 | 可能退化成统一复古滤镜 | 检查真实照片证据与可辨认遗迹是否同时存在 |
| 单一异物波普 | 独立实现 | 可能出现多个异物或贴纸堆叠 | 严格限制一个巨物并检查空间关系 |
| 微型人物涂鸦 | 独立实现 | 可能重画核心物件或加入过多人物 | 检查真实核心物件和两至四个有效动作 |
| 褪色纸页 | 独立实现 | 可能褪色过度导致主体消失 | 检查主体证据、低彩和留白是否平衡 |
| 当代水墨转译 | 独立实现 | 容易擅自出现书法、印章或普通水彩滤镜 | 未要求文字时，把文字和印章列为严重失败 |
| 自然人像补光 | 像素级后期 | 人物定位不准会导致补光区域偏移 | 限制人物框范围和曝光上限；完全不重绘人物与背景 |

## 尚需真人测试的边界

生成式场景仍然具有随机性，质量检查只能识别明显错误，不能保证每张图审美都一致。正式扩大邀请码前，应至少用建筑、人像、花草、食物和夜景各一张建立固定回归样本，并记录每个场景的通过率、手动再生成率和平均成本。
